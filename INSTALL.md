# Install guide — PvZ2 HACKED BY BUNS

This is a **custom IPA** (not the App Store game). Install it with **TrollStore** or **Sideloadly**.

## 1) Download the IPA

1. Open: https://github.com/FaZeBuns/PvZ2-Hacked-By-Buns/releases/latest  
2. Download **`PvZ2_Hacked_By_Buns.ipa`** (~1.4 GB)  
3. Wait for the full download (don’t open a half-finished file)

---

## 2A) Install with TrollStore (recommended)

TrollStore keeps the app installed permanently (no 7-day refresh).

1. Put the IPA on your iPhone (AirDrop, Files, Safari download, etc.)
2. Open **TrollStore**
3. Tap the IPA → **Install**
4. If install fails because an old build exists: delete **PvZ2 HACKED BY BUNS**, then install again
5. Launch the app from your Home Screen
6. You’ll see the **HACKED BY BUNS** popup once:
   - **Subscribe** → opens YouTube (popup stays open)
   - **OK** → closes the popup

Done.

---

## 2B) Install with Sideloadly (no TrollStore)

1. On a Windows/Mac PC, install [Sideloadly](https://sideloadly.io/)
2. Connect your iPhone with a cable and unlock it
3. Open Sideloadly → drag in `PvZ2_Hacked_By_Buns.ipa`
4. Enter your Apple ID → Start
5. On iPhone go to:  
   **Settings → General → VPN & Device Management** → trust the developer profile
6. Open the app

**Reminder:** with a free Apple ID, Sideloadly apps usually expire in about **7 days**. Re-sign with Sideloadly again when it won’t open.
